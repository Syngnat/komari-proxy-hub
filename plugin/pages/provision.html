创建 sing-box 节点

通过 Komari 远程执行，在节点上创建 VLESS + Reality 入站，并启用 Clash API 供流量统计使用。首版只支持 VLESS + Reality。

会修改节点配置：脚本会合并 sing-box 配置、生成备份、校验配置并重启 `sing-box` 服务。不会覆盖已有 tag；如果端口被占用或配置校验失败，脚本会停止。请先确认节点和参数。
